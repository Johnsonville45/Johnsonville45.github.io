# Johnsonville45.github.io

This repository hosts the GitHub Pages site for Johnsonville45, along with supporting project files and browser extension assets.

## Pahe Plus Browser Extension

The Pahe Plus extension source and documentation live in the `pahe-plus/` directory.

- Project directory: `pahe-plus/`
- Extension docs: `pahe-plus/README.md`
- Privacy notes: `pahe-plus/PRIVACY.md`
- Release artifacts: `pahe-plus/releases/`

## Repository structure

- `anime/` — site content and related assets
- `realestate/` — site content and related assets
- `pahe-plus/` — browser extension source, build output, release files, and docs

## Notes

- The website content in the root of this repository should remain separate from the extension source.
- The extension is currently an early development build and should be reviewed and tested before production use.
- See `pahe-plus/README.md` for installation, build, and release instructions.
