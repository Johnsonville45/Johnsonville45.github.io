# Features

## Current scope

- Browser extension scaffold
- Content-script injection
- Popup UI shell
- Shared browser compatibility helpers
- Separate Chromium and Firefox build paths

## Planned behaviors

The project is intended to add features around player interactions and browser-based website enhancement. At this stage, the repository contains a working project scaffold and documentation placeholders.

## Validation

The extension should be tested in a browser against the live website before being considered production-ready.
