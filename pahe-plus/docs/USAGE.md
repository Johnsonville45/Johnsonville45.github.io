# Usage

## Installation

1. Download the extension source from the project repository.
2. Open the `pahe-plus/` directory.
3. Load the extension in a Chromium or Firefox browser using the browser's extension developer mode.
4. Review the permissions and ensure the site is supported.

## Testing

Open a site and verify that the extension initializes without errors. Use the popup to confirm the background script responds as expected.

## Build workflow

- Use the Chromium build folder for Chrome / Edge testing.
- Use the Firefox build folder for Firefox extension packaging.
- Review the release notes before shipping a new version.
