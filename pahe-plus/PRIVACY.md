# Privacy Policy

## Pahe Plus

Version: 0.2.0

Pahe Plus is designed to operate as a browser extension that enhances the Pahe Plus experience on supported sites. This privacy policy outlines the expected data handling for the extension.

## What the extension may access

The extension may request permissions needed to access page content, browser tabs, and extension popup behavior. These permissions are limited to the functionality described in the project documentation.

## Data collection

This project does not intentionally collect or transmit personal data to a remote server. Any data accessed through the browser is expected to remain local to the browser and be used only to provide the extension behavior.

## Network access

If the extension adds remote network requests in future versions, those requests should be clearly documented and should not be used to exfiltrate personal data without explicit user consent.

## Security

This project should be reviewed before distribution to ensure that no unnecessary permissions or debug code are shipped.

## Contact

This repository is used for project hosting and source tracking. Review the project README for additional guidance.
